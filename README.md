# React Pokédex – Discover Pokémon with PokéAPI ⚡

A simple React application that fetches Pokémon data from the **[PokéAPI](https://pokeapi.co/)** and displays it in a beautifully styled Pokédex.  
You can search for Pokémon by name and explore their details like type, weight, and height.  

---

## 🚀 Live Demo  
🔗 [View Project on GitHub Pages](https://vaishnavigavhane.github.io/react-pokedex/)

---

## ✨ Features  
 ⚡ Built with **React + Vite**  
 🎨 Modern & responsive UI with styled cards  
 🔍 Search functionality for Pokémon by name  
 📡 Fetches data from **PokéAPI** in real-time  
 📱 Fully responsive design (desktop + mobile)  

---

## 🛠️ Tech Stack  
- **React 19**  
- **Vite** for fast development and build  
- **PokéAPI** for Pokémon data  
- **CSS** for styling
